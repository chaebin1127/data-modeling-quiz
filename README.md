# 데이터 모델링의 이해 퀴즈

정적 HTML/CSS/JavaScript로 만든 20문항 퀴즈입니다.

## 로컬 실행
`index.html` 파일을 브라우저에서 열면 실행됩니다.

## Vercel 배포
1. 이 폴더를 GitHub 저장소에 업로드합니다.
2. https://vercel.com 에서 로그인한 뒤 **Add New → Project**를 선택합니다.
3. 해당 GitHub 저장소를 Import 합니다.
4. Framework Preset은 **Other**, Build Command와 Output Directory는 비워 둔 채 Deploy를 누릅니다.
5. 배포가 완료되면 생성된 `vercel.app` 주소를 공유하면 됩니다.

별도 빌드 명령이나 서버 환경변수는 필요하지 않습니다.
